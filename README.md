Change Log (Part 2 to Final PoE)

The following changes were implemented since Part 2:

1. Multiple Screen Navigation

* Added React Navigation to support multiple screens.
* Created separate screens for Home, Add Menu, and Filter functionality.

2. Home Screen Improvements

* Moved menu item input fields off the Home Screen.
* Home Screen now displays the complete menu.
* Added display for total number of menu items.
* Added average price calculations for:
    * Starter dishes
    * Main dishes
    * Dessert dishes

3. Add Menu Screen

* Created a dedicated screen for adding menu items.
* Added functionality to:
    * Enter dish name
    * Enter description
    * Select course
    * Enter price
    * Add menu items
* Added functionality to remove menu items.

4. Filter Screen

* Created a separate Filter Screen.
* Added filtering options for:
    * All Menu Items
    * Starters
    * Mains
    * Desserts

5. Data Management

* Continued using arrays to store menu items.
* Improved state management to allow data sharing across screens.
